# Menu – OPTION: User Properties

- Location: File > User Properties
   - Function: Opens the configuration window for the currently logged-in user.
   - Behavior: Displays a dialog box containing user details (permissions, username, preferences).
   - Use Case: Use this to view account details or modify specific user settings.

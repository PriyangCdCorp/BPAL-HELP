# Menu – OPTION: Security Lockout

- Location: File > Security Lockout
   - Function: Locks the application interface instantly.
   - Behavior: Hides the current screen contents and requires a password to resume.
   - Use Case: Use this when stepping away from your desk (e.g., for lunch or a break) to prevent unauthorized access without fully logging out.

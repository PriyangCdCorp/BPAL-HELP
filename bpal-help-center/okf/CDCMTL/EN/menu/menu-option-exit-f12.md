# Menu – OPTION: Exit F12

- Location: File > Exit F12
   - Shortcut Key: F12
   - Function: Closes the BPAL Administration application completely.
   - Behavior: Terminates the software.
   - Use Case: Use this when you are completely done with the application and wish to close it on your computer.




**How do I close the BPAL program?**
A: You can close the program by clicking "File" and then selecting "Exit". Alternatively, you can press the F12 key on your keyboard.


**I am going to lunch, how do I secure my screen?**
A: Go to the "File" menu and select "Security Lockout". This will lock the screen without logging you out.


**Where can I see my user details?**
A: Navigate to "File" and select "User Properties" to view your account settings.


**Where are the error logs located?**
A: Go to the "File" menu and hover over "Log Files". This is a sub-menu that will show you the available logs.


**What is the difference between Logout and Exit?**
A: "Logout" ends your current session but keeps the BPAL application open. "Exit" (or F12) closes the application completely.

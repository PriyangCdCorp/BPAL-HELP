# Menu – OPTION : Verrouillage de sécurité

Emplacement : Fichier > Verrouillage de sécurité
Fonction : Verrouille instantanément l'interface de l'application.
Comportement : Masque le contenu de l'écran actuel et nécessite un mot de passe pour reprendre.
Cas d'utilisation : Utilisez cette option lorsque vous quittez votre poste de travail (par exemple, pour le déjeuner ou une pause) afin d'empêcher tout accès non autorisé sans vous déconnecter complètement.

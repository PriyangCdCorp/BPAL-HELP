# Knowledge Base – 13. Folder Split Bar and Scrollbars

A double-line **split bar** divides a folder grid into two sections, each with its **own horizontal scrollbar**. Drag the split bar left or right; the columns on one side remain horizontally stationary while the other side is scrolled. This is useful for retaining identifying information, such as Vendor Code and Name, while examining distant columns.

Users can explicitly **save the split-bar position** via the folder's **Options** menu or the folder's right-click context menu. Separately, BPAL has a **global setting to automatically save split-bar position upon closing folders**. This global auto-save option is **off until explicitly enabled**. Remembered positions are specific to the user and folder, so Vendor and Product can have different split positions.

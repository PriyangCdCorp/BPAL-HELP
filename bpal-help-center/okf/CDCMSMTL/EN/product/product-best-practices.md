# Product – Best Practices

1. **Use Lookup Fields:** Always use the magnifying glass icon for fields that have it - this ensures you select valid values
2. **Verify Selections:** Use the "i" icon to confirm you have selected the correct code before saving
3. **Use Apply for Ongoing Work:** If making multiple changes to a product, use Apply to save incrementally
4. **Use OK for Final Saves:** When finished with all edits, use OK to save and close in one action
5. **Review Before OK:** Before clicking OK, verify all entries are complete and accurate
6. **Use Cancel Cautiously:** Remember Cancel discards all changes - only use it if you want to exit without saving

# Product – Field Types and Visual Indicators

**Open Fields (White Background)**
Fields with a white or light background are available for data entry. Users can click on these fields and input or modify information. These fields are editable and can receive user input.

**Example:** The "Code" field, description fields, and the "Type" field in the product notebook are typically open fields ready for user input.

**Closed Fields (Gray Background)**
Fields with a gray background are locked and cannot be edited. These fields are read-only and display information that is either system-generated, auto-populated, or intentionally restricted from user modification. Users cannot enter or change data in closed fields.

**Example:** Fields that display calculated values, status fields, or fields managed by system rules may appear grayed out.

# Menu – OPTION : Quitter F12

Emplacement : Fichier > Quitter F12
Touche de raccourci : F12
Fonction : Ferme complètement l'application Administration BPAL.
Comportement : Met fin au logiciel.
Cas d'utilisation : Utilisez cette option lorsque vous avez complètement terminé avec l'application et souhaitez la fermer sur votre ordinateur.



**Comment fermer le programme BPAL ?**
R : Vous pouvez fermer le programme en cliquant sur « Fichier » puis en sélectionnant « Quitter ». Alternativement, vous pouvez appuyer sur la touche F12 de votre clavier.


**Je vais déjeuner, comment sécuriser mon écran ?**
R : Allez dans le menu « Fichier » et sélectionnez « Verrouillage de sécurité ». Cela verrouillera l'écran sans vous déconnecter.


**Où puis-je voir les détails de mon compte utilisateur ?**
R : Naviguez vers « Fichier » et sélectionnez « Propriétés de l'utilisateur » pour consulter les paramètres de votre compte.


**Où se trouvent les journaux d'erreurs ?**
R : Allez dans le menu « Fichier » et survolez « Fichiers journaux ». Il s'agit d'un sous-menu qui vous montrera les journaux disponibles.


**Quelle est la différence entre Déconnexion et Quitter ?**
R : « Déconnexion » met fin à votre session actuelle mais garde l'application BPAL ouverte. « Quitter » (ou F12) ferme complètement l'application.

# Menu – OPTION : Propriétés de l'utilisateur

Emplacement : Fichier > Propriétés de l'utilisateur
Fonction : Ouvre la fenêtre de configuration de l'utilisateur actuellement connecté.
Comportement : Affiche une boîte de dialogue contenant les détails de l'utilisateur (autorisations, nom d'utilisateur, préférences).
Cas d'utilisation : Utilisez cette option pour consulter les détails du compte ou modifier des paramètres utilisateur spécifiques.

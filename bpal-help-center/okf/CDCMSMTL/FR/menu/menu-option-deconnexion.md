# Menu – OPTION : Déconnexion

Emplacement : Fichier > Déconnexion
Fonction : Met fin à la session de l'utilisateur actuel dans l'application.
Comportement : Renvoie l'utilisateur à l'écran de connexion. Ne ferme pas la fenêtre de l'application, seulement la session active.
Cas d'utilisation : Utilisez cette option lorsque vous avez terminé de travailler mais souhaitez laisser l'application ouverte pour qu'un autre utilisateur puisse se connecter.

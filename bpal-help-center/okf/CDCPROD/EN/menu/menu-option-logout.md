# Menu – OPTION: Logout

- Location: File > Logout
   - Function: Terminates the current user's session within the application.
   - Behavior: Returns the user to the login screen. It does not close the application window, only the active session.
   - Use Case: Use this when you are finished working but want to leave the application open for another user to log in.

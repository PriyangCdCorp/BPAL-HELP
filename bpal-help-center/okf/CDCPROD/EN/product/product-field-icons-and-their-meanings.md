# Product – Field Icons and Their Meanings

**Magnifying Glass Icon (Lookup Table Field)**
The magnifying glass icon indicates that the field has a lookup table associated with it. This is standard functionality in BPAL for fields with this icon.

**Functionality:**
- Clicking on the magnifying glass icon opens a lookup dialog or dropdown menu
- The lookup table contains a predefined list of valid values for that field
- Users can select an appropriate value from the list instead of typing it manually
- Lookup fields ensure data consistency and prevent invalid entries
- The lookup helps users find and select the correct code or value quickly

**Example:** The "Type" field in the product notebook has a magnifying glass icon, allowing users to browse and select from available product types like "BROWNGRADE".

**Information Icon (Circular "i" Icon)**
Located to the right of the magnifying glass icon, this circular icon with the letter "i" provides quick access to additional information related to the code field.

**Functionality:**
- Pressing or clicking this icon opens an information popup or detail window
- The popup displays related data and descriptive information about the selected code
- This allows users to verify they have selected the correct code by viewing its details
- Helps users understand what each code represents without leaving the notebook
- Provides context-sensitive help and reference information

**Example:** Clicking the "i" icon next to a product type code would display the full definition, properties, and other details about that product type.

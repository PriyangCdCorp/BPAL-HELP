# Menu – OPTION : Fichiers journaux >

Emplacement : Fichier > Fichiers journaux
Indicateur visuel : Contient une flèche orientée vers la droite (>), indiquant un sous-menu.
Fonction : Accède aux journaux d'historique et de suivi des erreurs du système.
Comportement : Le survol de cet élément révélera une liste secondaire de types de journaux spécifiques.
Cas d'utilisation : Utilisé pour le dépannage des erreurs ou l'audit de l'historique du système.
